- **Lyrics carry on from song to song.** With Spotify, the next song's lines follow in the same list, through Spotify's mixes too. Skipping a song by hand has its own switch in Settings, and a skipped song's line now stops where the song did.
- **Up next.** The next song's cover and first lines are ready before it starts.
- **Spotify Canvas.** A song's looping clip plays behind the lyrics when it has one. Needs the Spotify sign-in, and can be turned off in Settings.
- **New cover change.** The new cover slides in over the old one, as in Spicy Lyrics.
- **Mic timing is remembered.** The timing you set for songs found with the mic is saved for each microphone. The check once a minute still catches the next song, but no longer moves the timing of the same song.
- **Update notices.** Syllable asks GitHub for a newer version when it opens, and Download hands the file to your browser. Can be turned off in Settings.

Install `Syllable-1.3.0.apk` over 1.2.1. Your settings stay. Needs Android 8.0 or newer.
